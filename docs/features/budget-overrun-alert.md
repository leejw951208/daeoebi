## 1. 무엇을 만들었나
가계부 예산 탭에서 이번 달 지출이 예산을 넘으면 대시보드 상단에 "이번 달 예산을 ₩N 초과했습니다." 앰버 경고 배너가 뜬다. 사용자는 남은 예산 숫자를 해석하지 않아도 초과 사실과 초과 금액을 바로 알 수 있다.

## 2. 왜 (배경·목표)
- 기존에는 초과를 남은 예산 글자·진행바를 빨간색으로 바꾸는 것으로만 알렸는데, 지출액은 원래 항상 빨간색이라 "초과"와 구분되지 않았다.
- 초과 여부와 초과 금액을 명시적인 문구로 한눈에 알리는 것이 목표다.

## 3. 핵심 결정

| 결정 | 이유 | 대안(버린 것) |
|------|------|----------------|
| 앰버(`--color-warning-*`) 배너 | 빨강(danger)이 지출액·진행바에 이미 과하게 쓰여 초과와 구분이 안 됨. 미사용이던 warning 토큰을 활용 | 빨강 danger 재사용 — 기존 빨강 요소와 섞임 |
| 초과했을 때만(`spent > budget`) 노출 | 단순·명확. 정확히 같으면 아직 초과 아님 | 임박(예: 90%) 2단계 경고 — 범위 축소 |
| 예산 0원이면 미표시 | 예산 미설정 상태엔 "초과" 개념이 없음 | 무조건 표시 — 미설정을 초과로 오인 |
| 판정을 순수 함수 `isOverBudget`로 분리 | `remaining`/`spentPct`와 같은 위치·규약, 단위 테스트 용이 | 컴포넌트 내 인라인 조건 — 테스트 어려움 |
